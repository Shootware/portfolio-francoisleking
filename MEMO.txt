  NOTES D'ARCHITECTURE
═══════════════════════════════════════════════════════════════

• Toute modification de contenu → fichiers /content uniquement
• Pas d'import direct de next-themes → passer par hooks/useTheme.ts
• Les glassmorphism cards → utiliser la classe .glass-card du globals.css
• Les animations scroll → toujours avec viewport={{ once: true }} pour perf
• TypeScript strict → pas de `any`, toujours typer les retours de fonction
• Images → toujours utiliser <Image> de next/image (jamais <img> natif)
